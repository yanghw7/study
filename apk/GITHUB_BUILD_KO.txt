GitHub에서 APK 만들기
1. 이 ZIP을 풀고 ComprehensiveJournalAndroid 폴더 안의 파일 전체를 GitHub 저장소의 루트에 업로드합니다.
2. 저장소의 Actions 탭 -> Build Study APK -> Run workflow를 누릅니다.
3. 빌드가 끝나면 실행 결과 아래 Artifacts의 Study-debug-apk를 받습니다.
4. 압축 안 app-debug.apk를 휴대폰에 설치합니다.

필요 설정: 없음. Supabase Redirect URLs에 diary://login 이 이미 등록되어 있어야 합니다.
