    🔌 API 선택

    통합 검색의 API 칸에서 쓸 AI를 고르세요. 무료 서비스 위주로 준비했고, ChatGPT·Claude 같은 유료 API는 아래 직접 추가 칸에서 설정해요. 여러 개를 고르면 검색할 때 모두에게 동시에 물어보고 탭으로 나눠 보여줘요. 각 칸의 ▲▼로 표시 순서를 바꾸고 [API 선택 저장]을 누르면 탭·목록 순서에 반영돼요.
    사용 여부·모델 이름은 [저장]을 누르면 GitHub 설정에 올라가 모든 기기에 반영되지만(각 페이지에서 [갱신]), API 키는 이 기기의 브라우저/앱에만 저장되고 GitHub에는 절대 올라가지 않아요. 키는 쓰는 기기마다 한 번씩 입력해야 해요.
    [카드 복사]를 누르면 설정과 이 기기의 키를 복사한 별도 API가 생겨요. 원본 서비스명 뒤에 번호가 붙어 인덱스에서 각각 검색할 수 있어요. 복사한 카드도 원본의 무료/유료 분류를 유지해요. 복사 카드는 [카드 삭제]로 없앨 수 있고, 다른 기기에 반영하려면 아래 [API 선택 저장]을 누르세요.

    ✂️ 화면 자르기

    구글·네이버 AI 화면을 띄울 때 위/아래/왼쪽/오른쪽을 잘라내는 값(px)이에요. 구글·네이버·통합 검색에 똑같이 적용되고, 저장을 누르면 각 페이지에서 [갱신] 때 반영됩니다.
    AI 화면을 좌우로 옮겨요. 양수(+)는 오른쪽, 음수(−)는 왼쪽으로 이동해요.
